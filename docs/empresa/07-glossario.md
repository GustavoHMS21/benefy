# Glossário

| Termo | Significado |
|---|---|
| **AI Orchestrator** | Quem lidera a estratégia de IA no SDLC e coordena os agentes e o roadmap (na Benefy, a Débora) |
| **Agente** | Programa que usa um LLM, ferramentas (tools) e contexto para executar uma tarefa com alguma autonomia |
| **ADR** | Architecture Decision Record: documento curto que registra uma decisão de arquitetura e o porquê |
| **Autorização** | Decisão em tempo real de aprovar ou negar uma compra |
| **BDD** | Behavior-Driven Development: descrever o comportamento esperado em linguagem de negócio (Gherkin) e usar isso como teste |
| **CAB** | Change Advisory Board: comitê que aprova mudanças sensíveis em produção |
| **Carteira** | "Bolso" de saldo do colaborador (VR, VA, Mobilidade, Saúde, Cultura, Livre) |
| **Deságio** | Desconto dado à empresa cliente na compra de créditos. Proibido no VR/VA pela Lei 14.442/2022 |
| **DLQ** | Dead-letter queue: fila para onde vão as mensagens que falharam várias vezes |
| **DoD / DoR** | Definition of Done / Definition of Ready |
| **Estorno** | Devolução de uma compra aprovada para as carteiras de origem |
| **Fallback** | Quando a carteira específica não tem saldo e o restante sai do Saldo Livre |
| **Gherkin** | Linguagem dos cenários BDD: Dado / Quando / Então |
| **GitFlow** | Modelo de branches com `main`, `develop`, `feature/*`, `release/*`, `hotfix/*` |
| **Lançamento** | Registro de débito ou crédito no extrato |
| **LLM-as-judge** | Usar um modelo de IA para avaliar a saída de outro, com uma rubrica |
| **MCC** | Merchant Category Code: código de 4 dígitos que define o ramo do estabelecimento |
| **MDR** | Taxa cobrada do estabelecimento em cada venda |
| **PAN** | Número do cartão |
| **PAT** | Programa de Alimentação do Trabalhador |
| **PO** | Product Owner |
| **Prompt injection** | Texto malicioso que tenta fazer o agente ignorar as instruções dele |
| **Quality gate** | Conjunto de critérios que o código precisa atingir para o pipeline deixar passar |
| **SAST** | Static Application Security Testing: análise de segurança do código sem executá-lo |
| **SCA** | Software Composition Analysis: análise de vulnerabilidades nas dependências |
| **SDLC** | Software Development Life Cycle: ciclo de vida do desenvolvimento (análise, refinamento, código, teste, deploy) |
| **Spec-Kit** | Toolkit do GitHub para desenvolvimento orientado a especificação com agentes |
| **TPV** | Total Payment Volume: volume total transacionado |
